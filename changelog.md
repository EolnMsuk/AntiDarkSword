## 5.0.0

- The only change is the version number, bumped to 5.0.0 for testing updates.

## 4.9.8

- Release packages now have names that identify their target. A native RootHide package joins the legacy rootful, modern rootful, rootless, and TrollFools downloads.
- Switching from Level 1 or 2 to Level 3 now starts with the Corellium Honeypot and all four System Daemon switches off.
- In Settings, tap **Updates** to check for the latest stable GitHub release. If a newer version is available, you can open its release page.
